PART I: INTRODUCTION TO EMBEDDED SYSTEMS (20 QUESTIONS)
--------------------------------------------------------------------------------

1. Definition: A combination of computer hardware and software designed to perform a specific function, often working as part of a larger device.
   Answer: Embedded System

2. Definition: Low-level software that directly controls a device's hardware and is usually stored in memory.
   Answer: Firmware

3. Definition: A processor that generally requires separate memory and peripheral circuits to function.
   Answer: Microprocessor

4. Definition: A small computer on a single chip that includes a processor, memory, and peripheral interfaces.
   Answer: Microcontroller

5. Definition: An integrated circuit that contains several processors and interfaces all on one chip.
   Answer: System on a Chip (SoC)

6. Definition: An integrated circuit that can be configured by a user to perform different custom hardware functions.
   Answer: Field-Programmable Gate Array (FPGA)

7. Definition: An integrated circuit designed for a specific function that is efficient when the function will not change.
   Answer: Application-Specific Integrated Circuit (ASIC)

8. Definition: A device that converts physical information from the environment into an electrical signal.
   Answer: Sensor

9. Definition: A component that changes an analog signal into a digital signal so a processor can read it.
   Answer: Analog-to-Digital Converter (A-D Converter)

10. Definition: A component that changes digital processor data into an analog signal.
    Answer: Digital-to-Analog Converter (D-A Converter)

11. Definition: A device that produces or controls a physical action or output based on system signals.
    Answer: Actuator

12. Definition: An operating system designed to manage task execution and hardware communication according to strict timing rules.
    Answer: Real-Time Operating System (RTOS)

13. Definition: Small and portable embedded systems, such as smartphones or wearables.
    Answer: Mobile Embedded Systems

14. Definition: Embedded systems connected to a network to send or receive data from other systems.
    Answer: Networked Embedded Systems

15. Definition: Embedded systems that perform a specialized task independently without relying on a host system.
    Answer: Standalone Embedded Systems

16. Definition: Small-scale embedded systems that typically rely on an 8-bit microcontroller.
    Answer: Small-Scale Embedded Systems

17. Definition: Software architecture where simple routines are repeatedly called in sequence to manage hardware functions.
    Answer: Simple Control Loop

18. Definition: Software architecture where specific hardware events pause main execution to trigger specific tasks.
    Answer: Interrupt-Controlled System

19. Definition: Software architecture where running tasks voluntarily cooperate to share processor time.
    Answer: Cooperative Multitasking

20. Definition: The process of finding and fixing problems in embedded software or hardware systems.
    Answer: Debugging

PART II: FIREBASE DATABASE (20 QUESTIONS)
--------------------------------------------------------------------------------

1. Definition: A Google suite of cloud-based tools and services for building, managing, and growing mobile and web applications.
   Answer: Firebase

2. Definition: A database model that does not require traditional table-based structures or rigid schemas.
   Answer: NoSQL

3. Definition: Firebase's original cloud-based NoSQL database optimized for fast data synchronization across clients, structured like a large JSON file.
   Answer: Realtime Database

4. Definition: A flexible, scalable NoSQL document database provided by Firebase that organizes data into key-value documents and collections.
   Answer: Cloud Firestore

5. Definition: Firebase service that checks and manages the identity of application users.
   Answer: Firebase Authentication

6. Definition: Service allowing developers to remotely change application appearance or behavior without publishing a new app version.
   Answer: Remote Config

7. Definition: Cross-platform messaging service that enables sending notification messages and data messages to users.
   Answer: Firebase Cloud Messaging (FCM)

8. Definition: Service providing real-time crash reporting and actionable stack traces to help debug app stability.
   Answer: Crashlytics

9. Definition: Firebase service providing insight into the performance characteristics and network latencies of an application.
   Answer: Performance Monitoring

10. Definition: Service allowing developers to distribute pre-release versions of apps to trusted testers for early feedback.
    Answer: App Distribution

11. Definition: Analytics tool measuring user engagement, event tracking, and in-app behavior metrics.
    Answer: Google Analytics

12. Definition: Tool using machine learning on analytics data to group users into segments based on predicted behaviors.
    Answer: Predictions

13. Definition: Smart URLs that direct existing or potential users to specific content locations inside an app.
    Answer: Dynamic Links

14. Definition: Feature comparing different user experience variations against each other to identify the most effective design or setting.
    Answer: A/B Testing

15. Definition: The online chat service built by James Tamplin and Andrew Lee from which Firebase originally evolved.
    Answer: Envolve

16. Definition: A bridge or set of defined protocols allowing two software applications to communicate with each other.
    Answer: Application Programming Interface (API)

17. Definition: The specific Firebase category containing Realtime Database, Firestore, Authentication, Remote Config, and FCM.
    Answer: Build Better Applications

18. Definition: The specific Firebase category containing Crashlytics, Performance Monitoring, and App Distribution.
    Answer: Improve App Quality

19. Definition: The specific Firebase category containing Analytics, Predictions, Dynamic Links, and A/B Testing.
    Answer: Grow Your App

20. Definition: An advantage of Firebase that makes it accessible for beginner projects and early prototyping.
    Answer: Free Plans

PART III: PROCESSORS IN EMBEDDED SYSTEMS (20 QUESTIONS)
--------------------------------------------------------------------------------

1. Definition: The main computational component of an embedded system that accepts inputs, processes data, and yields output.
   Answer: Processor

2. Definition: The processor sub-unit responsible for fetching instructions from memory.
   Answer: Control Unit (CU)

3. Definition: The processor sub-unit containing the ALU and circuits executing data transfer, conversion, and program control logic.
   Answer: Execution Unit (EU)

4. Definition: The fundamental operational sequence where a processor retrieves an instruction and executes it repeatedly in order.
   Answer: Fetch-Execute Cycle

5. Definition: A processor with a flexible instruction set architecture designed to handle a broad range of computing tasks.
   Answer: General Purpose Processor (GPP)

6. Definition: Category of instructions performing basic mathematical operations like addition, subtraction, or multiplication.
   Answer: Arithmetic Instructions

7. Definition: Category of instructions performing comparisons and logical bit operations like AND, OR, XOR, or NOT.
   Answer: Logical Instructions

8. Definition: Category of instructions managing program flow, including conditional jumps, loops, and return statements.
   Answer: Control Instructions

9. Definition: A single VLSI chip housing a CPU that typically relies on external peripherals and memory buses.
   Answer: Microprocessor

10. Definition: An integrated single-chip microcomputer housing a processor CPU, limited program memory, and built-in I/O capabilities.
    Answer: Microcontroller

11. Definition: A microprocessor specifically tailored for embedded systems, integrating peripherals on-chip to save power and space.
    Answer: Embedded Processor

12. Definition: A specialized embedded processor engineered for high-speed mathematical operations required in processing audio, video, and signals.
    Answer: Digital Signal Processor (DSP)

13. Definition: A microprocessor-based system-on-a-chip designed explicitly for real-time digital streaming video or image rendering.
    Answer: Media Processor

14. Definition: An integrated circuit dedicated to a specific application domain and commercialized to multiple client users.
    Answer: Application-Specific Standard Product (ASSP)

15. Definition: A SoC processor built by pairing a minimal core instruction set architecture with configurable logic for custom instructions.
    Answer: Application-Specific Instruction Processor (ASIP)

16. Definition: The hardware density standard representing full CPU integration onto a single silicon die.
    Answer: Very Large Scale Integration (VLSI)

17. Definition: Application domain typically handled by microprocessors rather than microcontrollers due to high compute demands.
    Answer: Personal Computers (or Servers / Scientific Computing)

18. Definition: Application domain ideal for microcontrollers due to integrated real-time control peripherals.
    Answer: Automotive Systems (or Appliances / Industrial Control)

19. Definition: Common DSP field analyzing wave data, sensor echoes, and radio detection patterns.
    Answer: Radar (or Seismology / Image Processing)

20. Definition: Specialized processor type that can easily outperform general-purpose processors in graphics rendering tasks.
    Answer: GPU (Graphics Processing Unit)

PART IV: ARCHITECTURE TYPES IN EMBEDDED SYSTEMS (20 QUESTIONS)
--------------------------------------------------------------------------------

1. Definition: The shared physical bus carrying data, address, and control signals between CPU, memory, and peripheral modules.
   Answer: System Bus

2. Definition: Computer architecture where instructions and data share the same single memory space and unified transmission bus.
   Answer: Von Neumann Architecture (Princeton Architecture)

3. Definition: The performance limitation that occurs when shared instruction and data access limits memory bus throughput.
   Answer: Von Neumann Bottleneck

4. Definition: Computer architecture utilizing separate memory units and dedicated independent buses for instructions versus data.
   Answer: Harvard Architecture

5. Definition: Dedicated high-speed memory cache restricted exclusively to storing code instructions in a Harvard structure.
   Answer: Instruction Cache (I-cache)

6. Definition: Dedicated high-speed memory cache restricted exclusively to storing operational data variables in a Harvard structure.
   Answer: Data Cache (D-cache)

7. Definition: Processor architecture designed around a small, uniform instruction set optimized for quick execution in a pipeline.
   Answer: Reduced Instruction Set Computer (RISC)

8. Definition: Processor architecture featuring a diverse, complex instruction set with varying instruction lengths.
   Answer: Complex Instruction Set Computer (CISC)

9. Definition: Internal elementary operations executed inside a modern processor core after decoding complex macro instructions.
   Answer: Micro-op (Micro-operation)

10. Definition: The original high-level machine code instruction (such as standard x86) prior to internal CPU micro-op decoding.
    Answer: Macro-op (Macro-operation)

11. Definition: The internal optimization process of merging multiple decoded macro-ops into a single executed micro-op.
    Answer: Instruction Fusion (Macro-ops Fusion)

12. Definition: Architectural feature in modern x86 chips used to break down complex macro instructions into RISC-like execution units.
    Answer: Instruction Decoder

13. Definition: Processor architecture category featuring legacy x86 instructions.
    Answer: CISC Architecture

14. Definition: Common embedded architecture family known for simple instructions, widely utilized alongside ARM and MIPS.
    Answer: RISC Architecture

15. Definition: Hardware technique used in processors to overlay execution steps of multiple instructions in a sequence.
    Answer: Pipelining

16. Definition: High-speed memory component positioned between CPU and main memory to reduce bus delays.
    Answer: Cache Memory

17. Definition: Alternative name for Von Neumann architecture based on the location where it was researched.
    Answer: Princeton Architecture

18. Definition: Primary architectural reason Harvard architecture excels at digital signal processing (DSP) operations.
    Answer: Greater Data-Memory Bandwidth

19. Definition: Internal register architecture strategy used by RISC systems to balance reduced command complexity.
    Answer: Large General-Purpose Register File

20. Definition: Major processor architecture standard listed alongside RISC, CISC, MIPS, and PowerPC as widely used in embedded microprocessors.
    Answer: SuperH
